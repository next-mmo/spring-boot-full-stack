# Agent Workflow Feedback

Local observations and upstream suggestions for `@next-mmo/agent-workflow-scrum`. These records supplement project instructions; they are not automatic policy approvals or proof of package defects.

Start with the [enterprise review](enterprise-review-2026-09-08.md) for priorities, existing safeguards, and verification limits.

| Case | Consult when | Attribution | Upstream status |
| :--- | :--- | :--- | :--- |
| [0001: Project direction alignment](0001-project-direction-alignment.md) | Product, audience, or delivery surface changes; a green check coexists with stale governing documents | Agent omission and semantic-check coverage gap; package bug not established | Not submitted |
| [0002: Human project overview](0002-human-project-overview.md) | Humans cannot see overall features, usable behavior, and progress from PRD/task records | Repository reporting gap; upstream enhancement candidate | Not submitted |
| [0003: Report integrity](0003-report-integrity.md) | Report counts/statuses disagree with tracked PRDs/tasks; canonical records disappear | Reproduced parser mismatch; source-level collection gaps | Not submitted |
| [0004: Approval and evidence enforcement](0004-approval-evidence-enforcement.md) | A company wants workflow checks to authorize completion, merge, or release | Structural-validator limitation; external enforcement needed | Not submitted |
| [0005: Review coverage](0005-review-coverage.md) | Automated review reports success for unsupported product languages | Reproduced zero-coverage success; integration hazard | Not submitted |
| [0006: Worktree ownership and cleanup](0006-worktree-ownership-cleanup.md) | Parallel agents claim tasks or clean up isolated workspaces | Source-level target-validation gap; coordination enhancement | Not submitted |
| [0007: Enterprise data boundaries](0007-enterprise-data-boundaries.md) | Optional retrieval or generated reports handle confidential content | Documented opt-in behavior; enterprise-policy extension | Not submitted |
| [0008: Distribution identity](0008-distribution-identity.md) | A company inventories or approves the installed workflow dependency | Consumer Git-install packaging mismatch | Not submitted |
| [0009: Project-owned skills](0009-project-owned-skills.md) | Doctor warns about legitimate local extensions | Reproduced diagnostic overreach | Not submitted |

Add or update cases through `.agents/skills/agent-workflow-feedback/SKILL.md`. Record exact versions, evidence, conditions, and limitations so later agents can decide whether a case still applies.
